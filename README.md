# Muzafferkadir Tap

## How do I install these formulae?

`brew install muzafferkadir/tap/<formula>`

Or `brew tap muzafferkadir/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "muzafferkadir/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
